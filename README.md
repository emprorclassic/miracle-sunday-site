# Miracle Sunday website

- `index.html` the page (design and animations). You rarely need to open it.
- `content.json` all the text, projects, courses, reviews and links. Edit it from the Pages CMS dashboard.
- `images/` photos and logo. Project screenshots go in `images/projects/`, course covers in `images/courses/`.
- `fonts/` drop the Labora font files here.
- `.pages.yml` settings for the Pages CMS dashboard.

Hosted on Cloudflare Pages. Every change saved to GitHub goes live in about a minute.
